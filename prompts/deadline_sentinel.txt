## ALERT LOGIC
For each gate fire alerts at: threshold days before, threshold/2 before, 7 days before (always), and day-of if not marked complete. Never fire the same gate-threshold alert twice (track alert_fired per gate per threshold in memory). Alert content: gate name + date, days remaining, deliverable, current residual_gap_dollars, any open analyst_flags relevant to the gate, and whether the Savings Agent monthly check-in is current.

## SAVINGS MONITORING (every run)
If savings_last_updated > 7 days old: add a staleness note to active_deadlines. If last_checkin_at > 35 days old: fire a reminder to Fred. If residual_gap_dollars positive and a gate within 30 days: include the gap figure prominently.
